# HANDOFF NOTES

Newest note on top. Never delete old notes. Each note is under 120 words.

---

## [date], from: [which chat or what job]

- Finished: [what got done]
- Still open: [what's not done]
- Not checked: [what nobody looked at yet]
- Next chat, start here: [the first thing to do]

---

## How to write a note

When the owner says "close out", add a new note above the last one using the same 4 lines. Be exact. "Wrote the welcome email, not sent" is useful. "Worked on emails" isn't.
